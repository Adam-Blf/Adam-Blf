## BLF Lab's

Mon studio de développement, entreprise individuelle immatriculée au RNE en août 2026.

en ligne : vitrines, applications métier, boutiques, outils internes.

## Architecture

Ce dépôt n'est pas qu'un README : trois workflows planifiés le tiennent à jour tout seul.

```mermaid
flowchart LR
  cron["Cron quotidien<br/>et workflow_dispatch"] --> svg["update_profile_svg.py"]
  api["API GitHub<br/>user, repos, commits"] --> svg
  tpl["terminal.template.svg<br/>palettes clair et sombre"] --> svg
  svg --> out["terminal-dark.svg<br/>terminal-light.svg"]
  ver["VERSION"] --> sync["sync_version.py"]
  sync --> readme["README.md<br/>badge version"]
  snake["snake.yml"] --> branch["branche output<br/>github-snake*.svg"]
  topics["sync-topics.yml"] --> repos["Topics des dépôts Adam-Blf"]
  out --> readme
  branch --> readme
```
